📝 Istruzioni:

  1. Clicca sui link qui sotto per aprire le pagine di Wikipedia/Wikimedia
  2. Clicca con il tasto destro sull'immagine del treno e seleziona "Salva immagine con nome..."
  3. Salva l'immagine con il nome esatto indicato (es: ETR_204_Pop.jpg)
  4. Metti tutte le immagini in una cartella
  5. Usa lo script Python per processarle e aggiungerle al progetto

🔧 Dopo il Download:

Una volta scaricate le immagini, puoi processarle automaticamente con questo comando:

python3 process_downloaded_images.py /path/to/your/downloaded/images/

Oppure aggiungile manualmente agli Assets.xcassets seguendo la struttura dei file già creati.

💡 Suggerimento:

Per ora l'app funziona con i placeholder colorati per i treni mancanti. Puoi aggiungere le immagini in seguito senza modificare il codice!

Il codice controlla automaticamente se l'immagine esiste, e se non c'è mostra il placeholder elegante.
